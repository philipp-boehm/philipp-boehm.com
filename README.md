# philipp-boehm.com

Statisches One-Page-Portfolio.

**Live-Ansicht:** [philipp-boehm.com](https://philipp-boehm.com)

## Architektur & Tech Stack

Das Projekt verfolgt einen strikten Zero-Dependency-Ansatz für maximale Langlebigkeit und minimale Wartung. Es kommen keine Build-Prozesse, Paketmanager oder Frameworks zum Einsatz.

- **Stack:** HTML5, CSS3 (Vanilla)
- **Struktur:** Single-File-Ansatz (CSS ist nativ eingebettet)
- **Hosting & Deployment:** GitHub Pages (automatisch bei Push in den `main`-Branch)
